postsmith drafts LinkedIn and X posts in the user's voice and scores them against a reference corpus. The user pastes posts by hand; nothing here logs into, posts to or scrapes LinkedIn or X.

Layout: corpus/ (reference posts, cards, features), style/ (persona, learned profiles, moves, lexicon, exemplars, taxonomies), drafts/ (runs), memory/ (lessons, topics, performance, published), evals/ (rubric, golden, health, calibration), tools/ (deterministic scripts), docs/design/ (contracts.md, content-quality-bar.md). The user's company context (product facts, competitive research, leadership's rules for the public voice) is private and lives outside this repo; its path is recorded under `## Company context` in style/persona.md, which is gitignored. Read it before any post about the company, its products, its space or a competitor, and never copy any of it into this repo.

Conventions:
- Run helpers as `uv run tools/<name>.py ...` from the project root. Every tool has --help and --json.
- docs/design/contracts.md is authoritative for every schema, path and CLI. Code that disagrees with it is the bug.
- corpus/heldout/, corpus/ratings.jsonl, evals/calibration.jsonl, evals/golden/, evals/disagreements.jsonl and memory/performance.jsonl are label stores: read them only when the skill you are running says to. Opening one early makes you a second, contaminated grader.
- Never edit text under corpus/. Inside /post, never write or edit candidate post text as the orchestrator; writers do that. /draft is the exception the user asked for: there you write the post yourself, with the lens file, moves and do-not-reuse list open, and checks run once.
- Any post, or any paragraph of a post, that narrates something that happened walks the /story skill (.claude/skills/story/SKILL.md) before anything else continues: the framework the user pasted on 2026-10-18, the two halves (the moment told from inside it, then numbered lessons) and the ten-line audit. Mandatory in every skill, no questions asked. No story post exists without it.
- style/lexicon.yaml is learned from the corpus and stays local; every tool falls back to the tracked style/lexicon.base.yaml (research tiers only) when it is missing.
- Day-to-day: /shortlist each morning finds three stories with a one-line joke and an image concept each; /draft turns the user's pick into facts, ten candidate lines for the place the post turns, then the dialogue, image prompt, captions and first comment built around the line they pick. They make the image; nothing here renders a UI. /post is the full tournament and is opt-in.
- A post "passes" only if a scores/<id>.merged.json written by tools/aggregate.py says so.
- The product is a post, not a report. A check's output is an edit: a false claim cuts or corrects its line, an overlap rewrites its span, a weak hook rewrites line 1. Every run ends with paste-ready text, and what a check could not fix is listed beside it as the user's call. "Pass" stays a precise word; delivery never waits on it.
